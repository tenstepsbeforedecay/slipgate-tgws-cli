# Зеркало Flowseal TG WS Proxy

**Консольная сборка для Windows x64, которую использует Slipgate.**

[Скачать бинарник](https://github.com/tenstepsbeforedecay/slipgate-tgws-cli/releases/latest) · [Оригинальный проект Flowseal](https://github.com/Flowseal/tg-ws-proxy) · [Проверить сборки](https://github.com/tenstepsbeforedecay/slipgate-tgws-cli/actions/workflows/build-cli.yml)

## Что это

[TG WS Proxy от Flowseal](https://github.com/Flowseal/tg-ws-proxy) помогает Telegram подключаться через WebSocket. Этот репозиторий автоматически собирает его консольную версию — без графического окна и значка в трее. В Slipgate запуском и настройками управляет само приложение.

Это отдельное зеркало сборок. Оригинальные исходники и разработка прокси находятся у **Flowseal**; здесь хранятся инструкции сборки и готовые файлы для Slipgate.

## Откуда берётся `.exe`

1. Раз в два часа GitHub Actions проверяет новые стабильные релизы Flowseal.
2. Если версия ещё не опубликована здесь, берёт исходники именно этого релиза и фиксирует точный коммит.
3. На отдельной Windows-машине GitHub собирает `TgWsProxy_windows.exe` с помощью PyInstaller.
4. Проверяет запуск справки, открытие локального порта, формат Windows x64 и соответствие описания параметров бинарнику.
5. Публикует готовый комплект только после проверок и сверки контрольных сумм загруженных файлов.

**Бинарник собирается из исходников Flowseal, а не копируется из неизвестного источника.** Ход каждой сборки открыт во вкладке [Actions](https://github.com/tenstepsbeforedecay/slipgate-tgws-cli/actions). Уже опубликованные версии автоматически не заменяются; при ошибке новый выпуск останавливается.

## Что скачивать

| Файл в релизе | Для чего нужен |
| --- | --- |
| **`TgWsProxy_windows.exe`** | Сам прокси для Windows x64. Python устанавливать не нужно. |
| `capabilities.json` | Описание параметров именно этой сборки для совместимого приложения. |
| `routing.json` | Дополнительные сведения о маршрутах для проверки и дальнейшей интеграции. |
| `build-info.json` | Точный коммит исходников и версии зависимостей сборки. |

Дополнительные JSON-файлы появляются в новых выпусках этого механизма. В старых релизах может быть только `.exe` — их содержимое сохраняется.

Если вы пользуетесь **Slipgate**, вручную скачивать файлы обычно не требуется: приложение получает бинарник из релизов этого репозитория. Отдельный `.exe` — консольная программа, а не установщик Slipgate. Его параметры можно посмотреть командой `TgWsProxy_windows.exe --help`.

## Проверки и ограничения

Ручной режим **`validate`** собирает и проверяет программу, сохраняя результат только как временный артефакт Actions. Он не создаёт релиз и не меняет опубликованные файлы. Обычный выпуск новых версий работает по расписанию.

Проверки сборки не гарантируют доступность Telegram в любой сети. Новые возможности прокси могут потребовать обновления Slipgate; дополнительные сведения о маршрутах сами по себе не обновляют встроенную диагностику приложения.

Подробности для сопровождения: [как устроены сборка, проверка и выпуск](docs/cli-release.md).
